# 根拠の一覧

このスキルの規則の根拠。公的機関・大学・業界団体・プラットフォームの公式資料だけを使い、他の人が作ったスキルは構成の参考にとどめた（最後の節）。根拠が見つからない規則は、本文に「慣用」または「私の判断」と書いてある。確認日はすべて2026年10月19〜20日。

## 敬語

- **文化審議会答申「敬語の指針」**（2007年2月2日）<https://www.bunka.go.jp/seisaku/bunkashingikai/kokugo/hokoku/pdf/keigo_tosin.pdf>
  - ページは本文に印字されたページ（PDF のページ番号は印字＋3）
  - 敬語が表すもの p.5／相互尊重と自己表現 p.7／5分類 p.13〜21／自分側は立てない p.22／尊敬語の形 p.24〜25／謙譲語Ⅰの形 p.26〜27／謙譲語Ⅱ p.18・28／二重敬語と敬語連結 p.30〜31／電子メールなど新しい媒体 p.10〜11
  - 第3章の問：過剰な敬語【5】p.35、ご〜される【7】p.36、ご〜できる【8】p.36、伺ってください【10】p.37、お持ちしますか【11】p.37、私のお考え【16】p.39、させていただく【18】p.40〜41、宛名の様・先生・御中【21】p.43、社外に自社の上司【24】p.44、ご苦労様【27】p.45〜46、とんでもございません【29】p.47、能力・意思を直接聞く【30】p.47〜48、前置きの無い依頼【32】p.48〜49、回りくどい許可の形【33】p.49
  - 指針に記載が無いもの：了解・承知・御社・貴社・各位・よろしかったでしょうか・〜のほう・おっしゃられる（「おっしゃられる」は二重敬語の一般規則 p.30 で判断）
- **文化庁「国語に関する世論調査」** 平成25年度 p.15（「おっしゃられた」の解説）、平成27年度（さ入れ言葉）

## 御社と貴社

- 厚生労働省（ハローワーク）「応募書類」パンフレット p.9 <https://www.mhlw.go.jp/content/11600000/001710225.pdf> ：応募先の敬称は「貴社」。「御社」は口語体なので文書には使わない。会社でないときの言い換え（貴法人・貴校・貴学・貴院など）
- 兵庫労働局「豆知識－１」<https://jsite.mhlw.go.jp/hyogo-roudoukyoku/content/contents/002058692.pdf> ：貴社は文語体、御社は口語体
- 専修大学「就職活動のマナー」<https://www.senshu-u.ac.jp/career/Job_Hunting_Guide/practice_01.html> ：書き言葉では「貴社」が一般的
- 緩和の見解：立教大学キャリアセンター「RIKKYO PLACEMENT GUIDE 2025」p.71（書類に「御」と書いても問題ない）、国立国語研究所「ことば研究館」Q&A <https://kotoba.ninjal.ac.jp/qa/yokuaru/qa-16/> （「御社」も書き言葉として通用する。絶対のルールにすべきではない）
- → check.py では「誤り」ではなく「注意」として扱う

## フリマ（メルカリ）

メルカリ公式ヘルプ `https://help.jp.mercari.com/guide/articles/<番号>/` 。ヘルプの記事には更新日の表示が無い（確認日 2026年10月20日）。

- /263/ 取引マナー：あいさつは決まりではないが勧める、丁寧な言葉遣い、感情的にならない（読み返す・時間を置く）、「○○円で買います」「○○円で即決します」と価格を指定しない、大幅な値下げを求めない、値下げに応じてもらえたらお礼、「専用」「取り置き」を求めない、取引メッセージでも個人情報を書かない
- /873/ 外部サービスなどに誘導する行為：SNS の ID・電話番号・外部で連絡する手段（QR コードを含む）を書かない
- /258/ 禁止されている行為：用意された以外の決済方法を促すこと、購入後の値引きの持ちかけ、評価への個人情報、評価方法の指定、評価変更の繰り返しの依頼、自己都合のキャンセル、キャンセル料・迷惑料の請求
- /363/ 取引メッセージ：送ったものは双方とも消せない／/820/ コメント：消せるのは出品者だけ、返答は義務ではない
- /104/ 販売価格の変更・交渉：応じられなければ断ってよい／/1403/ 値下げ依頼
- /1509/・/49/ 発送期限：発送までの日数の最長の日数。数え始めは支払いが済んだ時点。過ぎた翌日0:00からキャンセル申請ができる
- /2007/ 出品者ガイドライン（2025年12月15日改定）：発送通知は発送した後／/2014/ 購入者ガイドライン（2025年9月9日改定）：サイズ・使用感・傷は購入前に確かめる
- /108/・/63/ 支払い：期限は購入日を含む3日目の23:59:59。遅れるなら事前に取引メッセージで相談
- /115/ 自動の取引完了：らくらくメルカリ便は配達完了の2日後13時以降、ゆうゆうメルカリ便・その他は発送通知の9日後13時以降（2026年2月16日から。メルカリのお知らせ 2026年2月13日）
- /55/ 説明と違う・壊れていた：受取評価をせずに連絡、返事は24時間を目安に待つ、事務局へは到着から14日以内／/59/ 到着前の受取評価の依頼は断る／/1016/ 受取評価と評価コメント／/283/ 評価の変更／/751/ 届かない／/625/ 返品／/908/ 取引の妨げ（過度な情報開示や立証の強要）
- /281/ 取引のキャンセル：申請の前に相手に相談、「理由の詳細」はそのまま相手に表示される
- 取引メッセージの文例は、ヘルプには誤操作のとき（/59/・/629/）しか無い。このスキルの文例は自作

## チャット

- Slack ヘルプセンター（日本語）：「チャンネルやワークスペースに通知する」<https://slack.com/intl/ja-jp/help/articles/202009646>（@channel・@here は「注意が必要」）、「メンションを使用する」<https://slack.com/intl/ja-jp/help/articles/205240127>、「スレッドを使用して会話を整理する」<https://slack.com/intl/ja-jp/help/articles/115000769927>、「絵文字と絵文字リアクションを使う」<https://slack.com/intl/ja-jp/help/articles/202931348>（文字で反応する代わりに使える）、「メッセージの編集または削除」<https://slack.com/intl/ja-jp/help/articles/202395258>（取り消しは送信から15秒以内・デスクトップのみ、削除は復元できない）
- Slack 日本語ブログ（2025年3月21日）<https://slack.com/intl/ja-jp/blog/collaboration/etiquette-tips-in-slack>：「お疲れさまです」「失礼します」だけの DM は送らない、挨拶はメッセージの最初の行に、絵文字の例（👀 確認中・✅ 完了）
- RegTech コンソーシアム「Slackご利用の手引き」第3版（デジタル庁事務局、2024年3月22日）p.5 <https://www.digital.go.jp/assets/contents/node/basic_page/field_ref_resources/ba38fc37-b613-4ec0-8ab7-af57136114e1/3db66763/20240329_policies_regtechconsortium_guideline_01.pdf>：「お世話になります」などの慣用句は入れなくてよい、@channel・@here は控える
- 和光市「チャット活用指針」ver.1.0（2021年10月26日。市役所内の決まり）：前書きは書かない、返信不要ならその旨を書く、「見ました」かスタンプで返す
- 総務省「テレワーク時におけるコミュニケーション・マネジメント面の課題解決等に関する先進事例集」（令和4年度）<https://www.soumu.go.jp/main_content/000951833.pdf>：p.22 チャットは簡潔になるため冷たく感じられることがあり、語尾に注意する、p.14 用件に応じてチャット・メール・電話を使い分ける
- 厚生労働省「テレワークの適切な導入及び実施の推進のためのガイドライン」p.13 <https://www.mhlw.go.jp/content/000759469.pdf>：時間外のメール等の送付を控えることが有効
- 文化庁「国語に関する世論調査」令和6年度 結果の概要 <https://www.bunka.go.jp/koho_hodo_oshirase/hodohappyo/pdf/94274201_02.pdf>：メッセージで戸惑うこと「相手の感情が分かりにくい」45.0%・「返事や反応を迫られている感じ」27.4%（p.8）、気を付けたい点「誤解を招くような言葉を使わない」67.3%（p.21）。句点・絵文字・返信の速さを本人に聞いた設問は、令和元〜7年度に無い
- LINEヤフー：送信取消は送信から1時間以内、相手に「メッセージの送信を取り消しました」と出る（プレスリリース 2025年11月7日 <https://www.lycorp.co.jp/ja/news/release/019830/>）、既読でも返事が来ないときは相手の事情を考える（LINE セーフティセンター）、遅い時間の感じ方は人による（<https://www.lycorp.co.jp/ja/story/20240227/linemirai.html>）
- LINE の個人どうしの書き方（句点・1通の長さ・方言）には公式の指針が無い。敬語の指針 p.10〜11（新しい媒体でも相手と状況への気配りは同じ）と、利用者本人の過去の文面（profile）を根拠にする

## 問い合わせフォーム

調べた公式のフォームの注意書き（確認日 2026年10月20日）。

- 消費者庁「ウェブサイトについてのご意見・ご感想」<https://contact.caa.go.jp/caa/opinion-001.html>：全角1,000字以内、半角カタカナ・丸数字・特殊文字は使わない、数字は半角、個別の相談は消費者ホットライン188へ
- 新宿区「区政へのご意見・ご要望」<https://www.city.shinjuku.lg.jp/soshiki/211001kocho_00002.html>：回答は翌日からおおむね14日（土日・休日・年末年始を除く）、メールでは回答しない、記号は全角、回答を見るためのパスワードが画面に出る
- 早稲田大学 文学学術院のお問合せフォーム（入口 <https://www.waseda.jp/flas/cms/contact/>）：問い合わせ先と区分を選び、在学生は学籍番号が必須、Waseda メールを書く、件名欄は無い
- エディオン公式通販のお問い合わせ <https://www.edion.com/member/EPM02901.html>：4,000字以内、12桁の注文番号、ドメイン指定受信の許可、フリーメールには届かない例がある
- メーカーのサポート案内：ソニー <https://www.sony.jp/support/pa_common/info/index.html>（型名・製造番号・内容をできるだけ詳しく）、パナソニック <https://jp-pc-support.connect.panasonic.com/inquiry>（機種品番・製造番号・OS）
- e-Gov パブリック・コメント <https://public-comment.e-gov.go.jp/contents/help/faq>：約120分で画面が切れるのでメモ帳に書いて貼る、受付番号と控えの PDF、1意見6,000字まで
- 国民生活センター「相談時のポイント」<https://www.kokusen.go.jp/soudan/data/point.html>：送った画面や記録を残す
- 「1回に一つの用件」「挨拶・署名の書き方」は、調べたフォームのどれにも書かれていなかった（このスキルでは慣用として扱う）
