# 敬語の使い分け

段階3以上（敬語を使う相手）で読む。根拠は文化審議会答申「敬語の指針」（2007年）。ページは本文に印字されたページ、【 】は第3章の問の番号。指針に無く慣用で決まっているものは、最後の節に分けた。

## 誰の動作かで種類を決める

| 種類 | 何をするか | 使う場面 | 例 |
|---|---|---|---|
| 尊敬語 | 相手や第三者を立てる（p.14） | 相手の動作・状態・持ち物 | いらっしゃる・おっしゃる・ご覧になる・お読みになる・読まれる・ご存じだ |
| 謙譲語Ⅰ | 自分の動作の向かう先の人を立てる（p.15） | 相手に向かう自分の動作 | 伺う・申し上げる・拝見する・お届けする・ご案内する・いただく |
| 謙譲語Ⅱ | 自分の動作を、読み手に丁重に述べる（p.18） | 向かう先の無い自分の動作 | 参る・申す・いたす・おる・存じる・弊社 |
| 丁寧語 | 読み手に丁寧に述べる（p.20） | 文末 | です・ます・ございます |
| 美化語 | ものごとを上品に述べる（p.21） | 名詞 | お酒・お料理 |

- 自分側は立てない（p.22）。自分の家族、社外の人に話すときの自社の人も自分側
- 社外の人に自社の上司のことを書くときは「田中」「部長の田中」。「田中部長」は立てる呼び方になるので不適切（【24】）
- 謙譲語Ⅱは「ます」と一緒に使う（p.19）。「参る」だけで言い切らない
- 「お（ご）〜する」は、向かう先の人がいる動詞にしか作れない（p.27）。「ご乗車する」「お食べする」は作れない

## よく使う動詞

指針が挙げる形（p.24・26・28）。空欄は指針に特別な形が無いもの。その場合は一般の形（尊敬語＝お〜になる／〜れる、謙譲語Ⅰ＝お〜する）を使う。

| 普通の言い方 | 尊敬語（相手の動作） | 謙譲語Ⅰ（相手に向かう自分の動作） | 謙譲語Ⅱ（自分の動作を丁重に） |
|---|---|---|---|
| 言う | おっしゃる | 申し上げる | 申す |
| 行く | いらっしゃる・おいでになる | 伺う（訪ねる） | 参る |
| 来る | いらっしゃる・見える・おいでになる | | 参る |
| いる | いらっしゃる・おいでになる | | おる |
| する | なさる | | いたす |
| 見る | ご覧になる | 拝見する | |
| 聞く・尋ねる | お聞きになる | 伺う・お聞きする | |
| 知る | ご存じだ | 存じ上げる | 存じる |
| 思う | | | 存じる |
| 会う | お会いになる | お目に掛かる | |
| もらう | | いただく | |
| くれる | くださる | | |
| 食べる・飲む | 召し上がる | | |
| 見せる | | お目に掛ける・ご覧に入れる | |
| 借りる | | 拝借する | |

## 二重敬語にしない

一つの語に同じ種類の敬語を二重に使うのは、一般に適切ではない（p.30）。

| 二重敬語 | 直した形 |
|---|---|
| お読みになられる（指針の例） | お読みになる |
| おっしゃられる | おっしゃる |
| ご覧になられる | ご覧になる |
| お越しになられる | お越しになる・いらっしゃる |

- 習慣として定着しているので使ってよいもの：お召し上がりになる・お見えになる・お伺いする・お伺いいたす（p.30）
- 「て」でつないだ敬語連結は二重敬語ではなく、基本的に許容される：お読みになっていらっしゃる・お読みになってくださる（p.30）

## 「させていただく」

使ってよいのは、(1) 相手の許可を受けて行い、(2) そのことで恩恵を受ける、という場面（【18】p.40）。

| 文 | 判断 |
|---|---|
| 資料をコピーさせていただけますか | 許可を求めているので合っている |
| 発表させていただきます | 許可が無いなら「発表いたします」の方が簡潔（【18】） |
| 本日、休業させていただきます | 同上。「休業いたします」 |
| ○○高校を卒業させていただきました | 許可も恩恵も無いので不適切と判断される（【18】） |

1通の中で何度も使わない。自分で決めたこと・自分がすることは「いたします」で書く。

## 間違えやすい形

check.py は、このうち「拾う」と書いたものを機械で拾う。

| 間違えやすい形 | 直した形 | 理由・根拠 | check.py |
|---|---|---|---|
| ご確認してください・ご連絡していただけますか | ご確認ください・ご連絡いただけますか | 「お（ご）〜する」は謙譲語Ⅰなので、相手の動作に付けられない（p.31・【10】） | 拾う |
| 担当者に伺ってください | 担当者にお聞きください・お尋ねください | 「伺う」は謙譲語Ⅰ（【10】） | 拾う |
| ご出席されますか・ご確認された | ご出席になりますか・確認された | 「ご〜される」は尊敬語の適切な形ではないとされている（p.25・【7】） | 拾う |
| ご利用できます | ご利用になれます・ご利用いただけます | 向かう先の無い動詞に「ご〜できる」は作れない（p.25・【8】） | 拾う |
| 私のお考え・私のご都合 | 私の考え・私の都合 | 自分のものごとに尊敬の「お・ご」を付けている（【16】） | 拾う |
| 山田先生御中 | 山田先生 | 「御中」は組織あての脇付け（【21】） | 拾う |
| 書いていただいてもよろしいですか | 書いていただけますか | 簡潔に頼める場面では回りくどい（【33】） | 拾う（注意） |
| ご苦労様でした（目上へ） | ありがとうございました・お疲れ様でした | 目上には用いない方がよい（【27】） | 拾う（注意） |
| （相手に）お持ちしますか | お持ちになりますか | 謙譲語Ⅰを相手の動作に使っている（【11】） | 拾わない（文脈が要る） |
| ○○部長様・○○社長様 | ○○部長・○○様 | 役職と「様」が重なる（慣用） | 拾わない |
| 前置き無しの「これ、お願いします」 | 「恐れ入りますが、〜をお願いできますか」 | 前置きが無いと突然に感じられる（【32】） | 拾わない |
| 英語は話せますか（上の人に能力を聞く） | 英語もお話しになりますか | 上の人の能力・意思を直接たずねない（【30】） | 拾わない |

## 指針が「問題ない」としているもの（直さない）

- 褒められたときの「とんでもございません」（【29】）
- 「ご利用いただきまして」と「ご利用くださいまして」はどちらも適切（【17】）
- 相手に「ご持参ください」「お申し出ください」（【14】）
- 先生を「お待ちしています」、山田さんに「ご説明したい」（【16】）
- 社長に「そのように申し伝えます」（【15】）

## 指針に無く、慣用で決まっているもの

- **御社と貴社**：厚生労働省（ハローワーク）の応募書類の案内は「書類は貴社。御社は口語体なので文書には使わない」とする。一方、国立国語研究所は「御社」も書き言葉として通用するとし、どちらかを絶対のルールにすべきではないとしている。立教大学キャリアセンターも「書類に御と書いても問題ない」とする。既定はメール・書類では「貴社」。相手が会社でなければ「貴法人」「貴校」「貴学」「貴院」など（同じハローワークの案内）。迷ったら「○○株式会社様」でもよい
- **了解と承知**：指針に記載なし。「了解は目上に失礼」という説の根拠は確認できない。ただし読み手がそう信じていれば損をするので、段階3以上の相手には「承知しました」「かしこまりました」を既定にする（私の判断）
- **各位**：「各位様」としない
- **教員の宛名**：「○○様」も誤りではないが、学生からは「○○先生」の方が適切（【21】）。「先生様」「○○教授様」としない

## 丁寧すぎにしない

指針は「敬語をたくさん使えば丁寧になるというわけではない」とする（【5】p.35）。日本ビジネスメール協会の実態調査では、AI が書いたと見抜く手がかりの上位に「慇懃無礼なほど丁寧すぎる」（45.52%）が入っている。

- 「お」「ご」を付けすぎない：「お打ち合わせのおスケジュールとお資料」→「打ち合わせの日程と資料」
- 「恐れ入りますが」「お手数ですが」などのクッション言葉は、依頼の前に一つ
- 「何卒」「大変」「心より」を1通に重ねない
- 「〜させていただきたく存じます」は「〜いたします」「〜したいと考えております」で足りることが多い
