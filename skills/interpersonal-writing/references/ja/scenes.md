# 用件ごとの型

該当する節だけを読む。各節は「入れる要素（この順番で）」と「気をつけること」。例の［ ］は、本人に確かめて埋める所。分からないまま推測で埋めない。

根拠の略称：指針＝敬語の指針（【 】は問の番号）／実態調査＝日本ビジネスメール協会「ビジネスメール実態調査2026」。出典の詳細は references/sources.md。

## 目次

1. 依頼
2. 質問・問い合わせ
3. 不具合・トラブルの連絡
4. 苦情・返金や交換の依頼（買った側から）
5. お礼
6. お詫び・欠席や遅刻の連絡
7. 断り・辞退
8. 催促・確認
9. 日程調整
10. 提出・報告
11. 返信

## 1. 依頼

入れる要素
1. 何を頼むかを一言（「〜をお願いしたく、ご連絡いたしました」）
2. 背景を短く（なぜ必要か）
3. 頼む中身：誰に・何を・いつまでに
4. 相手の手間を減らす情報（必要な資料・手順・候補日）
5. 結び

気をつけること
- 「できればこの日まで」と「この日が締切」を書き分ける
- 本当に急がないときだけ「お手すきの際に」と書く。期限があるなら期限を書く
- 前置きのクッション言葉は一つ（指針【32】は前置きの無い依頼を問題とし、【33】は回りくどい許可の形を避けるとしている）
- 推薦状や締切の延長など相手の負担が大きい依頼：背景、なぜこの人に頼むのか、必要な書類、締切、提出方法を全部書き、十分な余裕をもって頼む。断れる余地も残す（「ご都合が難しい場合は、遠慮なくお知らせください」）

## 2. 質問・問い合わせ

入れる要素
1. 名乗り（就活なら大学・学部・学年、教員宛なら授業名と学籍番号）
2. 何についての質問か。どの案内の、どの記述についてかを特定する
3. 自分で確認したこと（読んだ資料、試したこと）
4. 質問。二つ以上なら番号を振る
5. 結び

気をつけること
- 書く前に、相手の公式の案内・よくある質問・募集要項を読む。読めば分かることを聞かない（早稲田大学文化構想学部の問い合わせ案内も、先によくある質問を見るよう案内している）
- 相手が選ぶだけで答えられる形にする。例：「特別選考枠のご案内をお待ちすればよいでしょうか。それとも、応募フォームから改めて応募すべきでしょうか。」
- 二つの資料の記述が食い違って見えるときは、両方の記述をそのまま並べて、どちらに従えばよいかを聞く

例（就活の問い合わせ）
```
［会社名］
［部署］ ［担当者名］様

お世話になっております。
［大学］［学部］［学年］の［氏名］です。

［日付］のご案内で、［案内の記述］と拝見しました。
一方で、［別の資料］には［別の記述］と書かれています。

［質問：選択肢を並べる］
ご教示いただけますと幸いです。

お忙しいところ恐れ入りますが、よろしくお願いいたします。

［署名］
```

## 3. 不具合・トラブルの連絡

案内どおりに進まない（ファイルが開けない・招待が届かない・ログインできない）ときの連絡。

入れる要素
1. 名乗り（プログラム名・班・氏名・番号）を一文で
2. 催促ではなく確認の形で切り出す（「本日、前日のご案内を拝見し〜」）
3. 起きていることを1件ずつ並べる。うまくいっているものも書く（相手が原因を切り分けやすくなる）
4. こちらで済ませた対応（再読み込み・別の端末・案内の手順書の確認）
5. 頼みたいことを一つ（「招待の再送などご対応いただけますと幸いです」）

## 4. 苦情・返金や交換の依頼（買った側から）

入れる要素
1. 何の契約・購入かを特定する：購入日・商品名・注文番号・金額
2. 何が起きたか（経緯）を時系列で短く
3. どうしてほしいか（返金・交換・修理・解約）と、その理由
4. 添える記録：やり取りしたメール、画面の写し、契約書、領収書
5. 連絡先と、連絡がほしい方法

気をつけること
- 書く前にひと呼吸置き、冷静に書く。要求と理由をはっきり書き、事業者の説明も聞く姿勢を残す（消費者庁「消費者が意見を伝える際のポイント」）。読む担当者は問題を起こした本人ではないことが多い
- 消費生活センターがあっせんするときも、事業者への書面に書くのは「契約の経緯と要望」（東京都中野区の案内）
- 回答の期限を書くかどうか：日本の公的な案内には期限を書く指示が見つからなかった。英語圏の消費者向けの案内（米国 FTC・英国 Citizens Advice）は期限を書くとしている。書くなら「［日付］までにご回答いただけますと幸いです」程度にとどめる（私の判断）
- ネット通販には法律上のクーリング・オフが無い。まず事業者の返品の決まりを確かめる。決まりが無ければ、受け取った日を含めて8日以内なら送料を自分で払って返品できる（国民生活センター）。クーリング・オフできる契約で通知するなら、契約年月日・商品名・契約金額・販売会社・返金と引き取りを求める一文・発信日・住所・氏名を書く（国民生活センター）
- 送った文面と画面は保存する。フォームから送るなら、送信前の画面を写しておく（国民生活センター・FTC）
- 脅すような言い方・相手を責める言い方をしない（消費者庁の資料は、行き過ぎた言動は強要罪・恐喝罪になりうると注意している）

## 5. お礼

入れる要素
1. 何についてのお礼か（日付と場面）
2. 具体的に役立ったこと・印象に残ったことを一つ
3. それを受けて自分がどうするか（あれば）
4. 結び

気をつけること
- 面接・面談・OB訪問のお礼は当日中に送る（追手門学院大学の案内）
- 一般的な褒め言葉（「大変勉強になりました」だけ）で終わらせず、何が役立ったかを一つ具体的に書く
- 相手に返信の手間をかけたくないときは「ご返信には及びません」と添えてもよい（慣用）

## 6. お詫び・欠席や遅刻の連絡

入れる要素
1. 何についてのお詫びかを最初に（事実）
2. 原因（自分の側で分かっている範囲で、主語をはっきり）
3. 済ませた対応と、これからの対応
4. 再発を防ぐために何をするか（具体的に）

気をつけること
- お詫びの言葉は1回はっきり書く。重ねない。返信が遅れたことのお詫びも1回で、すぐ本題に入る
- 「誤りが生じました」のように主語の無い書き方をしない。「私の確認不足で、［何を］誤りました」
- 「善処いたします」「真摯に受け止めます」のような中身の無い決意を書かない。何をするかを書く
- 授業を欠席するときは、欠席することと、その事情を担当教員に連絡する（早稲田大学文化構想学部の案内。手段は Waseda Moodle の Message My Teacher など）

## 7. 断り・辞退

入れる要素
1. 声をかけてもらったこと・選んでもらったことへのお礼
2. 結論（断る・辞退する）をはっきり
3. 理由を短く（言える範囲で）
4. お詫びを一言
5. 今後につながる一言（あれば）

気をつけること
- 結論をぼかさない。「前向きに検討させていただきます」で実質的に断るような書き方をしない
- 内定や選考の辞退は、誠実にはっきり伝える。連絡をしないまま放置しない（早稲田大学キャリアセンター）
- 辞退を決めたら、なるべく早く連絡する（相手は次の手配がある）

## 8. 催促・確認

入れる要素
1. いつ・何をお願いしたか（日付と件名）
2. 今の状況を確認したい、という形で切り出す（「その後いかがでしょうか」）
3. 新しい期限と、その理由
4. 難しい場合の逃げ道（「難しければ、見込みの時期だけでもお知らせいただけますと助かります」）

気をつけること
- 責める書き方にしない。相手のメールが届いていない可能性も残す
- 前回のメールに返信する形にして、やり取りを一つのスレッドにまとめる

## 9. 日程調整

入れる要素
1. 何のための日程か
2. 候補を箇条書きで3つほど。日付・曜日・開始時刻・所要時間
3. 形式（対面かオンラインか、場所）
4. どれも合わないときの一言（「ご都合が合わない場合は、候補をお知らせいただけますと幸いです」）

気をつけること
- 日付には必ず曜日を付ける。曜日が合っているかは check.py が確かめる
- 相手の候補から選ぶときは、選んだ日時をそのまま書き写して返す（「［日付］（［曜日］）［時刻］でお願いいたします」）

## 10. 提出・報告

入れる要素
1. 何を提出・報告するか（授業名・課題名、案件名）
2. 添付ファイルの名前
3. 補足（締切との関係、注意点）

気をつけること
- 済んだこと・まだのことを確かめて時制を選ぶ。発表の前に「先日発表いたしました」と書かない
- 本文で「添付します」と書いたら、ファイルが付いているかを確かめる
- Waseda Moodle の Message My Teacher はファイルを添付できない（教員向けの利用マニュアル）。添付が要るときは別の手段を確かめる

## 11. 返信

気をつけること
- 相手の質問には全部、聞かれた順に答える（実態調査で、不快に感じたメールの1位は「質問に答えていない」44.29%）
- 件名の「Re:」は残す
- 引用は必要な部分だけ
- 相手が日時を示してきたら、確定した日時を復唱する
