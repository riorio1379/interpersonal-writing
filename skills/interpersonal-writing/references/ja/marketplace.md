# フリマの取引メッセージとコメント

段階4（外の相手）で書く。メルカリを例にした。ほかのフリマでも、そのサービスの決まりを先に確かめれば、同じ考え方で書ける。根拠はメルカリ公式のヘルプとガイドライン（references/sources.md）。ヘルプの番号は help.jp.mercari.com/guide/articles/<番号>/ の番号。

## メールとの違い

- 宛名・件名・署名は書かない。相手は取引画面で誰とのやり取りか分かっている
- 「お世話になっております」は使わなくてよい（慣用）。最初の1通は「はじめまして」「ご購入ありがとうございます」で始める
- 最初のコメント・取引メッセージであいさつをすると、気持ちよく取引を進められる。あいさつは決まりではない（取引マナー /263/）
- です・ます で書く。敬語を使わない書き方や流行り言葉は相手を不快にさせうる（/263/）
- 送った取引メッセージは、出品者も購入者も消せない（/363/）。コメントを消せるのは出品者だけ（/820/）。書いたら一度読み返し、腹が立っているときは時間を置いてから送る（/263/）

## 書いてはいけないもの

| 書かないもの | 理由 | check.py |
|---|---|---|
| SNS の ID・電話番号・メールアドレス・外部サイトの URL・QR コード | 外部への誘導は禁止（/873/）。外部での直接の振込を求める詐欺を防ぐため | 拾う（誤り） |
| メルカリの決済以外での支払い（PayPay で直接・口座に振込 など） | 用意された以外の決済方法を促すことは禁止（禁止されている行為 /258/） | 拾う（誤り） |
| 自分や相手の本名・住所・郵便番号 | コメントと評価コメントは誰でも読める。取引メッセージでも個人情報は書かない（/263/） | 拾う（注意。本名は profile の name で見る） |
| 「○○円で買います」「○○円で即決します」 | 購入者が価格を指定する言い方は避ける（/263/） | 拾わない |
| 「専用にしてください」「取り置きでお願いします」 | 取り置きや専用出品の機能は無く、独自のルールを求めることは避ける（/263/） | 拾わない |
| 購入した後の値引きの相談 | 禁止（/258/） | 拾わない |
| 評価の書き方の指定・評価を変えてほしいという繰り返しの依頼 | 禁止（/258/・/283/） | 拾わない |

## 場面ごとの型

例の［ ］は、取引画面で確かめて埋める所。

### 1. 購入前の質問（コメント）

1. あいさつと、購入を考えていること
2. 聞きたいことを一つずつ。二つ以上なら番号を振る
3. 結び

- サイズ・使用感・細かな傷は、購入前に出品者に確かめる（購入者ガイドライン /2014/）。中古品のサイズには数mm〜数cmの誤差があるとされている
- 写真を足してほしいときは、どこを写した写真が欲しいかを具体的に書く
- 返事は義務ではない（/820/）。返事が無くても催促を重ねない

```text
はじめまして。購入を検討しています。
［聞きたいこと］を教えていただけますか。
よろしくお願いいたします。
```

### 2. 値下げの相談（コメント）

1. あいさつ
2. 購入したい気持ち
3. 値下げできるかの相談。金額を出すなら「〜円でご検討いただくことは可能でしょうか」と相談の形にする
4. 結び

- 「○○円で即決します」のような、こちらから価格を決める言い方にしない（/263/）
- 大幅な値下げは求めない（/263/）。どこまでが大幅かの数字は公式に無い
- 値下げに応じてもらえたら、お礼を言う（/263/）
- 出品者は、応じられないときは断ってよい（/104/）。断るときは理由を一言（送料・手数料を引いた額で出していることなど）添えると角が立たない（慣用）

```text
はじめまして。こちらの商品の購入を考えています。
［金額］円でご検討いただくことは可能でしょうか。
難しければ、このままの価格で検討します。
よろしくお願いいたします。
```

### 3. 購入された直後のあいさつ（出品者から）

1. 購入のお礼
2. 発送の予定日（日付と曜日）と発送の方法
3. 結び

- 発送の期限は、出品時に決めた「発送までの日数」の最長の日数。数え始めは支払いが済んだ時点（/1509/）
- 期限に間に合わないと分かったら、すぐに取引メッセージで予定日の変更を相談する（/1509/）
- 「ご購入させていただき」は誤り。購入するのは相手なので「ご購入いただき」

```text
ご購入ありがとうございます。
［日付］（［曜日］）に、［配送方法］で発送します。
到着まで少々お待ちください。
```

### 4. 発送の連絡

- 発送を知らせるのは「発送通知」のボタン。押すのは発送した後（出品者ガイドライン /2007/）
- メッセージを添えるなら、発送したことと、届くまでの目安だけを短く書く

### 5. 受け取りの連絡と評価（購入者から）

- 届いた物を確かめてから受取評価をする。問題が無いと確かめるまで「評価を投稿する」を押さない（/1016/）
- 到着の前に受取評価を頼まれても、断る（/59/）
- 評価コメントは誰でも読める。個人情報は書かない（/263/）。「良かった」なら良かった点やお礼を書く。「残念だった」なら、相手が理由を分かるように書く（/1016/）
- 一度した評価は、「残念だった」から「良かった」への変更とコメントの削除のほかは変えられない（/283/）

```text
本日受け取りました。説明どおりの状態で、丁寧に梱包していただきありがとうございました。
```

### 6. 届いた物に問題があるとき（購入者から）

1. 受け取ったこと
2. 説明と違う点・壊れていた点を、事実で一つずつ。写真があることを書く
3. どうしてほしいか（返品・キャンセルの相談など）
4. 結び

- 受取評価をせずに、出品者に商品の状態を連絡する（/55/）
- 返事は24時間を目安に待つ（/55/）。解決しなければ、商品が届いてから14日以内に事務局に問い合わせる（/55/）
- 出品者の同意なく、返品やキャンセルの申請をしない（/625/）
- 過度な情報の開示や立証を求めない（取引の妨げ /908/）。相手を責める言い方にしない（/263/「感情的にならない」）

```text
本日受け取りました。
確認したところ、［問題の箇所］が［どうなっているか］でした（写真を撮ってあります）。
商品説明には［説明の記述］とあったため、［返品・キャンセル］についてご相談できますでしょうか。
よろしくお願いいたします。
```

### 7. 商品が届かないとき（購入者から）

- 発送までの日数を過ぎても発送されないときは、期限の翌日0:00からキャンセルの申請ができる（/49/）
- 発送後に届かないときは、まず出品者に届いていないことを連絡する（/751/）。受取評価の画面の「取引を自動完了しない」を押しておく（/1016/）
- 受取評価が無いと自動で取引が終わる：らくらくメルカリ便は配達完了から2日後の13時以降、ゆうゆうメルカリ便とその他の配送方法は発送通知から9日後の13時以降（/115/。9日後は2026年2月16日からの決まり）

### 8. キャンセルを申し出るとき

1. お詫びと、キャンセルをお願いしたいこと
2. 理由（短く、事実で）
3. 返金や返品の段取り
4. 相手にしてもらうこと（申請への同意など）

- キャンセル申請の前に、取引メッセージで相手に相談する（/281/）
- 申請画面の「理由の詳細」は、そのまま相手に表示される（/281/）
- 自分の都合のキャンセル（出品者：商品の傷・紛失・売り切れ、購入者：誤って購入・要らなくなった）は禁止行為にあたる（/258/）。キャンセル料・迷惑料を求めるのも禁止（/258/）

### 9. 支払いが遅れるとき（購入者から）

- 支払いの期限は、購入した日を含めて3日目の23時59分59秒（/108/）
- 間に合わないなら、期限の前に取引メッセージで相談する（/63/）

## 送る前の確認

- 電話番号・SNS・URL・本名・住所が入っていないか（check.py が拾う）
- 日付と曜日が合っているか（check.py が拾う）
- 価格を指定する言い方・取り置きのお願いになっていないか
- 腹が立った状態で書いていないか。読み返したか
