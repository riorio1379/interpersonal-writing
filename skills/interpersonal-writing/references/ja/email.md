# ビジネスメールの構成

段階3〜5のメールで使う。根拠の詳細は references/sources.md。根拠が慣用（公的な文書に書かれていない、広く行われている書き方）のものは「慣用」と書いた。

## 順番

宛名 → 挨拶 → 名乗り → 要旨（用件を一言） → 詳細 → 結び → 署名

日本ビジネスメール協会の「基本の型」と同じ順番。要旨を名乗りの直後に置き、相手が最初の数行で用件を分かるようにする（九州大学附属図書館「和文メールの形式」も、冒頭で用件を一言書くとしている）。

## 件名

- 件名だけで「誰から・何の用件か」が分かるようにする（東海大学キャリア就職担当・九州大学附属図書館）
- 形は「用件（所属 氏名）」。例：「面接日程のご相談（○○大学 山田花子）」「○○論レポートの提出（文学部 山田花子）」
- 教員宛は件名に授業名を入れる（早稲田大学の案内は「○○に関する質問」の形を示している）
- 相手から件名の書き方の指定があれば、それに従う
- 返信では件名を変えない（「Re:」を残す）。用件が変わったら新しいメールにする（慣用）

## 宛名

| 相手 | 書き方 |
|---|---|
| 担当者の名前が分かる | 株式会社○○ 人事部 山田様 |
| 名前が分からない | 株式会社○○ 採用ご担当者様 |
| 組織・部署そのもの | 株式会社○○ 人事部 御中（「御中」と「様」は一緒に使わない） |
| 複数の相手に同じ文面 | 関係者各位（「各位様」としない） |
| 教員 | ○○学部 山田先生（「先生様」としない） |

- 会社名は略さず、正式な名前で書く（「(株)」にしない）。東海大学の案内は宛名に「様」「御中」の使い分けを挙げている
- 1行目に会社名、2行目に部署と名前、のように2〜3行に分けてよい

## 挨拶

| 段階 | 書き方 |
|---|---|
| 4（やり取りがある外の相手・教員） | 「お世話になっております。」 |
| 5（初めての相手） | 「初めてご連絡いたします。」「突然のご連絡失礼いたします。」（慣用） |
| 相手のメールへの返事 | 「ご連絡ありがとうございます。」で始めてもよい（慣用） |

- 時候の挨拶（「○○の候」）や「拝啓」は使わない（福岡労働局「就活OnePointAdvice⑥」）
- 「いつも大変お世話になっております」のように言葉を足さない。段階の中でいちばん簡素な形にする

## 名乗り

挨拶の直後に、所属と氏名を一文で書く。

- 就活：「○○大学○○学部3年の山田花子です。」（応募者番号などがあれば、名乗りか署名に入れる）
- 教員宛：学部・学年・学籍番号・氏名と、どの授業の受講者かを書く（早稲田大学は学籍番号と氏名を必須としている。東京工業大学「Study Tips」も名乗りに講義名を入れるとしている）
- 初めての相手：どこで連絡先を知ったか、なぜ連絡したかを一文足す

## 要旨と詳細

- 用件を一言で先に書く。「○○について、△△をお願いしたくご連絡いたしました。」
- 結論を先に、理由や経緯は後に短く（日本ビジネスメール協会）
- 日時・場所・金額・手順は箇条書きにする
- 質問が二つ以上なら番号を振り、相手が番号で答えられるようにする（慣用。ビジネスメール実態調査では、不快に感じたメールの1位が「質問に答えていない」で、送る側が相手の答えやすさを作る意味がある）
- 日付には曜日を付ける。曜日が合っているかは check.py が確かめる
- 相手の資料やメールの内容に触れるときは、どの資料の何かを特定して書く（「8月7日のご連絡で〜と拝見しました」）

## 結び

- 基本は「よろしくお願いいたします。」
- 内容に合わせる（東京工業大学「Study Tips」）：依頼なら「ご検討いただけますと幸いです。」、返事が必要なら期限を添えて「○日までにご返信いただけますと助かります。」
- 「お忙しいところ恐れ入りますが」は、相手に手間をかける依頼のときに一度だけ

## 署名

- 氏名（ふりがな）・所属・電話・メールアドレスを入れる（東海大学キャリア就職担当は署名に4項目を挙げている）
- 住所や固定電話は、書かないのが一般的（専修大学キャリア支援の案内）
- 返信でも毎回入れる（慣用。相手は多くの人と並行してやり取りしているので、毎回たどらなくて済む）
- profile に署名があれば、そのとおりに入れる

## 教員宛で気をつけること

- どこから送るかを先に確かめる。授業の連絡は、学習支援システム（Moodle など）のメッセージ機能が正式な手段になっている大学がある。例：早稲田大学の文化構想学部・法学部・日本語教育研究センターは、担当教員への連絡を Waseda Moodle の「Message My Teacher」とし、所属学部・学籍番号・氏名・科目名を書くよう求めている。このメッセージ機能は文字だけで、ファイルを添付できない
- メールで送るときは、大学から配られたメールアドレスから送る（九州大学附属図書館。早稲田大学でも理工学術院などは Waseda メールを指定している）
- 教員から連絡方法の指示があれば、それに従う
- 締切の延長やお詫びなど重い用件は、理由を短く事実で書き、どうしてほしいかを一つに絞る

## 送る前の確認

- 宛先・CC は合っているか。BCC にすべき相手を CC に入れていないか
- 本文で「添付します」と書いたファイルが付いているか。ファイル名は相手が見て分かるか
- 相手の名前・会社名の漢字は、相手のメールや公式サイトから写したか
- 日付と曜日が合っているか（check.py が確かめる）
