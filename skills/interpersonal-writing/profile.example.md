# 対人文章の設定（profile）の見本

このファイルは見本です。自分用の設定は、これを写して次の場所に置きます。

```bash
mkdir -p ~/.config/interpersonal-writing
cp profile.example.md ~/.config/interpersonal-writing/profile.md
```

別の場所に置くときは、環境変数 `INTERPERSONAL_WRITING_PROFILE` にパスを入れます。スキルの更新でこのファイルが上書きされないよう、スキルのフォルダの外に置きます。

スキルはこのファイルを毎回最初に読みます。下の toml のブロックは `scripts/check.py` も読みます（署名の抜けと、使わない語の検査）。それ以外の見出しは、文面を書くときの指示として読まれます。

## 機械検査の設定

```toml
name = "山田 花子"          # 冒頭で名乗っているかの検査に使う

# 署名。--context で種類を選ぶ。指定がなければ default
[signatures.default]
text = """
山田 花子（やまだ はなこ）
電話：090-0000-0000
メール：hanako@example.com
"""
required = ["山田 花子", "電話：", "メール："]   # 末尾にこの文字列が全部あるかを見る

[signatures.job]
text = """
山田 花子（やまだ はなこ）
○○大学 ○○学部 3年
電話：090-0000-0000
メール：hanako@example.com
"""
required = ["山田 花子", "大学", "電話：", "メール："]

# 使わない語。levels は段階（0〜5）、media は媒体で絞る
[[rules]]
levels = [0]
forbid = ["私は", "僕は"]
message = "家族宛の一人称は「花子」"
fix = "花子は"
```

## 相手ごとの段階

| 相手 | 段階 | 主な媒体 | メモ |
|---|---|---|---|
| 母・父 | 0 | LINE | |
| 大学の友人 | 1 | LINE | |
| アルバイト先の同僚 | 2 | LINE グループ | |
| アルバイト先の店長 | 3 | LINE | |
| ゼミの先生 | 4 | 大学のメール | 件名に授業名、本文に学籍番号 |
| 就活の企業 | 4（初回は5） | メール | 署名は job |

## 呼び方・一人称

- 家族宛の一人称：花子
- 母＝お母さん、父＝お父さん

## 書き癖

段階ごとの普段の書き方。下書きをこれに合わせる。

- 家族・友人：1通を短くして何通かに分ける。句点は付けない
- 職場のチャット：です・ます。了解の返事は「承知しました！」

## 文面の渡し方

- 件名と本文を分けて会話に出す
